# Class experiments

The experiments from each session, set up so you can run them yourself, with our runs to compare against.

| Week | Folder | What the experiments ask |
|---|---|---|
| 1 | [week-1/](week-1/README.md) | How much does what surrounds the model change its answers about code it hasn't seen? Seven experiments on seeded PetClinic, from the naked agent to skills and diagrams |
| 2 | [week-2/](week-2/README.md) | Can an agent make a change safely? One bug in PetClinic, from reproducing it to fixing it behind a sensor |
| 3 | [week-3/](week-3/README.md) | What can review settle before a person sees the change? One PetClinic feature through review before code, sensors, independent review and triage, then the reviewer tested on planted flaws |

Each week's README says what you need and how to run it. All run Claude Code in Docker, with the token from `claude setup-token`. Week 3 can also run a Codex reviewer, with an OpenAI API key.
