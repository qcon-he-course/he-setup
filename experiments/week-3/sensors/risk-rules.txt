# Risk rules for PetClinic: read by risk-floor.py (the tier) and test-delta.py (the
# protected checks). They live in the harness, outside the repository, so a change
# cannot edit the rules that classify it.
#
# <tier> <surface> <match> <pattern>
#   tier:   mechanical < bounded < material < critical. A change's floor is the
#           highest tier of any rule it triggers. A file no rule matches is bounded.
#   match:  path   a path glob (** crosses directories, * does not)
#           added  a regex searched in the change's added lines (all files)
#           pom    a new <dependency> or <plugin> in pom.xml (no pattern)
#
# Tiers follow the reference document (research/notes/2026-08-28-...md, 4.2):
# critical for auth, CI, and the checks that judge the change; material for
# persistence, concurrency, dependencies, build and configuration.
